# personal portfolio
Updated personal portfolio for my personal freelance business.

## Project metadata standard

Every page in `_projects/` fills the same front matter fields. Credits start with a `Studio` row, then roles in a fixed order (creative director, producer, art director, director of photography, concept, character design, 2D animation, 3D animation, lighting and texturing, motion design, editing, colour, sound). Leave a field empty if it doesn't apply. Never copy a generic tools list. Full rules: `Project Metadata Standard` in the Oscorp vault (`03 - Personal Brand/Portfolio Site`).
