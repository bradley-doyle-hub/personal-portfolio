# personal portfolio
Updated personal portfolio for my personal freelance business.

## Project metadata standard

Every page in `_projects/` fills the same front matter fields. The role line is Brad's own credit. The credits list shows other people only. Studio is not a credit row, and a page with no other names has no credits block. Labels, in order: Producer, Creative director, Director, Art director, Director of photography, Design, Animation, Lighting and texturing, Editing and colour, Music and sound. Leave a field empty if it doesn't apply. Never copy a generic tools list. Full rules: `Project Metadata Standard` in the Oscorp vault (`03 - Personal Brand/Portfolio Site`).
